Install

Two minutes, no installer.

Current builds are not yet signed and notarized, so your system asks you to confirm the first launch. After that, it opens like any other app.

macOS

  1. Download the zip for your Mac and open it to unzip.
  2. Move PDF Reader to your Applications folder.
  3. Open it. This build is not notarized, so macOS blocks the first launch.
  4. Open System Settings, go to Privacy and Security, and click Open Anyway next to the PDF Reader message.

Windows

  1. Download the zip and extract it to a folder.
  2. Keep pdfium.dll in the same folder as pdf-reader.exe.
  3. Run pdf-reader.exe. This build is not code signed, so SmartScreen may warn on first launch.
  4. Click More info, then Run anyway.
Verify

Check what you downloaded.

Every release publishes SHA-256 checksums. Compare the output with the matching line in SHA256SUMS.txt.

macOS, in Terminal

cd ~/Downloads
shasum -a 256 pdf-reader-macos-arm64.zip

Windows, in PowerShell

cd $HOME\Downloads
Get-FileHash pdf-reader-windows-x64.zip -Algorithm SHA256

Build from source

Prefer to build it yourself?

Install Rust stable and uv. On macOS, install Xcode and select its command-line tools. If GPUI reports a missing Metal compiler, run xcodebuild -downloadComponent MetalToolchain.

On Windows, use the MSVC Rust toolchain and install Visual Studio Build Tools with the Desktop development with C++ workload and the Windows SDK.

The setup script downloads PDFium for your platform and verifies its pinned SHA-256 digest. It needs Python 3.12 or newer, which uv can provide.

Clone

git clone https://github.com/joelfickson/pdf-reader.git
cd pdf-reader

Run

uv run scripts/setup_pdfium.py
cargo run --release

Package a macOS app

uv run scripts/package_macos.py
open "target/release/PDF Reader.app"
